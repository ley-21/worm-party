# 🐍 지렁이 파티

반 친구들끼리 **6자리 방 코드**로 모여서 하는 slither.io 스타일 멀티플레이 지렁이 게임입니다.

## 게임 방법
1. 닉네임과 **숫자 6자리 방 코드**를 입력하고 입장 (없는 코드면 새 방이 만들어짐, "🎲 새 방 코드 만들기" 버튼도 있음)
2. 친구들에게 코드를 알려주고 같은 코드로 입장 (1명 ~ 최대 30명)
3. **전원이 "준비완료"** 를 누르면 3초 카운트다운 후 시작
4. 마우스(또는 손가락) 방향으로 이동, **클릭 / 스페이스바 / 모바일 부스트 버튼**으로 가속 (가속하면 몸이 줄어듦)
5. 내 머리가 다른 지렁이 몸에 닿거나 벽에 닿으면 탈락 → 1등 관전
6. 마지막 1명이 남거나 **3분**이 지나면 종료, 순위 발표 후 대기실로 돌아가서 다시 준비완료로 다음 판

순위: 생존자(길이순) → 탈락자(늦게 탈락한 순)

## 내 컴퓨터에서 실행 (같은 교실 와이파이에서 하기)
[Node.js](https://nodejs.org) (18 이상) 설치 후, 이 폴더에서:

```bash
npm install
npm start
```

- 내 컴퓨터: `http://localhost:3000`
- 같은 와이파이의 친구들: `http://내컴퓨터IP:3000` (예: `http://192.168.0.12:3000`)
  - IP 확인: Windows는 `ipconfig`, Mac은 `ipconfig getifaddr en0`
  - Windows 방화벽이 물어보면 "허용"을 눌러야 접속돼요
  - 학교 와이파이가 기기끼리 접속을 막아두면 안 될 수 있어요 → 아래 인터넷 배포 방법 사용

## 인터넷에 올리기 (어디서나 접속) — Render 무료
1. 이 폴더를 GitHub 저장소에 올림
2. [render.com](https://render.com) 가입 → **New → Web Service** → 저장소 선택
3. Build Command: `npm install`, Start Command: `npm start`, Instance Type: **Free**
4. 배포가 끝나면 나오는 `https://xxxx.onrender.com` 주소를 친구들에게 공유

> 무료 플랜은 15분 동안 아무도 접속하지 않으면 잠들어요. 첫 접속 때 30초~1분 정도 기다리면 깨어납니다. 수업 전에 미리 한 번 열어두세요.

Railway, Fly.io 등 WebSocket을 지원하는 Node.js 호스팅이면 어디든 됩니다.

## 설정 바꾸기
`server.js` 맨 위 설정값에서 바꿀 수 있어요.

| 값 | 기본 | 설명 |
|---|---|---|
| `MAX_PLAYERS` | 30 | 방 최대 인원 |
| `ROUND_SECONDS` | 180 | 한 판 제한 시간(초) |
| `COUNTDOWN` | 3 | 시작 카운트다운(초) |
| `BASE_SPEED` / `BOOST_SPEED` | 5 / 10 | 이동 속도 |
| `START_MASS` | 15 | 시작 길이 |
